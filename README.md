# TikTok Mod Web

Вертикальная лента публичных видео TikTok в браузере (Android и ПК). Без регистрации, без базы данных, без токенов TikTok.

## Как получаются настоящие видео

У TikTok нет открытой публичной ленты без авторизации:

| Способ | Можно ли использовать |
|---|---|
| Display API | Нет: работает только с видео пользователя, который сам вошёл через OAuth |
| Research API | Нет: доступ выдаётся только одобренным академическим организациям |
| Сторонние парсеры | Нет: требуют обхода защиты TikTok |
| **oEmbed + Embed Player v1** | **Да: официальные, публичные, без ключей** |

Сайт читает список ссылок на публичные видео из `data/videos.json` (и ссылки, добавленные пользователем кнопкой «+»).
Каждая ссылка проверяется официальным `https://www.tiktok.com/oembed`: автор, описание, хештеги, музыка и превью берутся оттуда.
Удалённые и приватные видео отбрасываются. Видео играет в официальном плеере `https://www.tiktok.com/player/v1/<id>`.

Ограничения (честно):
- Рекомендательной ленты TikTok и счётчиков лайков через oEmbed нет, поэтому «For You» здесь — собственный алгоритм (категории, лайки, избранное, просмотры).
- Раздела «Популярные» нет: нужной статистики источник не даёт.
- Каталог формируете вы: в `data/videos.json` лежат 101 публичная ссылка (мемы, Minecraft, животные, игры, юмор), найденные через поиск. Часть из них со временем может исчезнуть — недоступные ролики отбрасываются автоматически. Добавляйте свои ссылки в файл или через «+». Когда видео в каталоге заканчиваются, лента начинает новый проход по каталогу.
- Звук: браузеры разрешают его только после настоящего жеста (клик мыши, тап, клавиша). Прокрутка колесом и свайп не считаются, поэтому пока вы не коснулись экрана, сверху показана красная кнопка «Нажмите, чтобы включить звук».
- Скорость: каталог кэшируется на CDN и в localStorage, следующий ролик начинает грузиться только когда текущий уже играет.
- Плеер TikTok — это iframe, который перехватывает касания. Поэтому поверх него лежит прозрачный слой жестов (свайп, мышь, колесо, тап). Из-за этого в ролике нельзя нажимать элементы самого плеера. Автор, описание и ссылка «Открыть в TikTok» показаны поверх видео.

## Автопополнение ленты (новые ролики каждые N минут)

Сайт сам подбирает новую порцию роликов раз в N минут (по умолчанию 5):
1. Сервер (`/api/discover`) делает один запрос в поисковый API по очередной теме («#minecraft #fyp», «#catsoftiktok #funny», …) и очередной странице выдачи.
2. Из выдачи берутся только ссылки вида `tiktok.com/@автор/video/ID`.
3. Каждая ссылка проверяется официальным oEmbed TikTok, недоступные отбрасываются.
4. Новые ролики подмешиваются в ленту сразу после следующего и сохраняются в браузере (до 300 штук).

С самим TikTok никакого парсинга и обхода защиты нет: ссылки приходят из поисковой выдачи, а проверка идёт через официальный oEmbed. Страница с поиском должна быть публичной и проиндексирована, поэтому свежайших роликов поиск может не знать, а выдача зависит от поисковика.

Это необязательная функция, без ключа сайт работает на списке из `data/videos.json`. Чтобы включить:

1. Получите ключ **одного** из API:
   - **Brave Search API** (brave.com/search/api): по официальной странице есть бесплатный план на 2 000 запросов в месяц. Проверьте условия при регистрации: есть сообщения, что бесплатный тариф менялся.
   - **Serper** (serper.dev): 2 500 бесплатных запросов один раз, карта не нужна, дальше платно.
   - Google Custom Search для новых клиентов закрыт, поэтому не поддерживается.
2. В Vercel: **Project → Settings → Environment Variables** добавьте `BRAVE_API_KEY` (или `SERPER_API_KEY`), при желании `DISCOVER_INTERVAL_MIN`. Нажмите **Redeploy**.
3. Откройте на сайте «+»: в блоке «Автопополнение ленты» должна появиться зелёная галочка.

Запрос в поиск делается не чаще одного раза за интервал, сколько бы людей ни открыло сайт (ответ кэшируется на CDN). Но при постоянном трафике интервал 5 минут это до 8 640 запросов в месяц, а бесплатного лимита Brave хватает примерно на интервал 30 минут (`DISCOVER_INTERVAL_MIN=30`).

## Управление

- Свайп вверх / вниз (телефон), перетаскивание мышью, колесо мыши, стрелки ↑ ↓ (J / K), PageUp / PageDown — следующий / предыдущий ролик.
- Тап или пробел — пауза. Первый тап на телефоне включает звук (браузеры запрещают автозвук без жеста).
- Лайк, избранное, поделиться, полноэкранный режим, обновление ленты, категории.
- Хранится локально (`localStorage`): лайки, избранное, история, свои ссылки, настройки, последняя категория.

## Запуск

```bash
npm install
npm test        # логика жестов, ленты, рекомендаций, разбора oEmbed
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Деплой на Vercel

1. Загрузите папку на GitHub (`git init && git add . && git commit -m "init" && git push`).
2. На vercel.com нажмите **Add New → Project** и импортируйте репозиторий.
3. Framework Preset определится как **Next.js**. Переменные окружения не нужны. Нажмите **Deploy**.
4. Откройте выданный адрес `*.vercel.app` на телефоне в Chrome. Чтобы убрать адресную строку, выберите меню → «Добавить на главный экран».

## Структура

```

src/app/api/feed/route.ts   проверка каталога через официальный oEmbed

src/lib/feedEngine.ts       жесты, окно смонтированных плееров, бесконечная очередь
src/lib/recommend.ts        подбор: For You, случайные, категории, избранное, история

src/lib/discover.ts         автопополнение: запрос в поисковый API + проверка oEmbed
src/lib/discoverCore.ts     темы, слоты времени, выбор ссылок на ролики из выдачи
src/app/api/discover/route.ts  эндпоинт автопополнения (кэш на CDN)
src/hooks/useStore.ts       localStorage
src/components/Feed.tsx     лента, жесты, управление плеером через postMessage
src/components/VideoSlide.tsx, Sheet.tsx, Icons.tsx
tests/feed.test.ts
```


## Аккаунты, профили и социальные функции (Supabase)

Ветка `feature/supabase-social` добавляет регистрацию/вход через Supabase Auth, публичные профили с уникальными никнеймами, поиск пользователей, подписки, синхронизацию лайков, личное избранное и историю просмотров. Видеолента, алгоритм рекомендаций и локальный кэш остаются в проекте.

### Настройка

1. Создай проект Supabase.
2. Открой SQL Editor и выполни целиком `supabase/schema.sql`.
3. В Vercel → Project → Settings → Environment Variables добавь:
   - `NEXT_PUBLIC_SUPABASE_URL` — Project URL.
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` — publishable/anon key.
4. Повтори для Preview/Development при необходимости и сделай Redeploy.

Используется только публичный anon/publishable key в браузере; service_role key добавлять нельзя. Таблицы защищены RLS: избранное и история приватны, пользователь может менять только собственный профиль и данные, подписка создаётся от имени вошедшего пользователя.

### Тесты

`npm test` запускает имеющиеся тесты алгоритма ленты и рекомендаций. `npm run build` проверяет production-сборку. Проверка реальной регистрации/почты и политик RLS требует настроенного проекта Supabase и тестового аккаунта.
